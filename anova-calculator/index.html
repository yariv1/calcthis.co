      How to use the ANOVA calculator

      Put each group’s values in its own box, separated by commas, spaces or new lines, or paste a table from a spreadsheet: one column per group, or two columns holding the value and the group name. The result updates as you type. With only sizes, averages and standard deviations, choose Summary.

      The page picks the test from your data and says why. Under Go advanced you can choose the test and the pair comparisons yourself, leave outliers out, set the confidence level, plan for an expected effect and set the decimal places.

      The one-way ANOVA formula

      F = MS between ÷ MS within MS between = Σ n × (group mean − grand mean)² ÷ (k − 1) · MS within = Σ (value − its group mean)² ÷ (N − k) · k = number of groups · N = number of values

      Classic, Welch or Kruskal-Wallis?

      The classic ANOVA assumes similar spread in every group and roughly normal values. Welch’s version drops the equal-spread assumption. Kruskal-Wallis replaces the values with their ranks. For the teaching example the three give F = 19.3214 (p = 0.000177), F = 20.5348 with 2 and 7.83 degrees of freedom (p = 0.0007669) and H = 10.4637 (p = 0.005344). Levene’s test gives p = 0.7954 and Shapiro-Wilk p = 0.7391, so the classic test is recommended.

      Post hoc tests

      Tukey compares every pair with the pooled spread and suits the classic ANOVA. Games-Howell uses each pair’s own spread and goes with Welch. Dunn compares average ranks after Kruskal-Wallis. Bonferroni multiplies each t-test p-value by the number of pairs and is the most cautious and simplest of them.

      Reading the picture

      Each group sits on the same scale: every value as a dot, a box around the middle half of the values with a line at the median, the average as a tick and its interval as a bar. Letters summarise the comparisons: two groups with a letter in common are not shown to differ. Pick a pair in the table to see its difference and interval against zero. The page also reruns the test without each group in turn, so you can see whether one group carries the result.

      Effect size and sample size

      Cohen’s f measures how far apart the group averages are compared with the spread inside them. In the teaching example it is very large, so 3 values per group would already give 80% power at those averages. Effects seen in small studies tend to shrink, so plan with the smallest effect that matters.

      Common questions

      What is ANOVA?

      ANOVA (analysis of variance) tests whether the averages of several groups differ by more than chance would produce. It compares the spread between the group averages with the spread of the values inside the groups. Their ratio is the F statistic.

      When should I use ANOVA instead of a t-test?

      Use ANOVA when you compare three or more groups. Running a t-test on every pair raises the chance of a false alarm. With two groups the classic ANOVA and the equal-variance t-test give the same p-value.

      How do I read the F value and p-value?

      A larger F means the group averages are further apart compared with the noise inside the groups. A p-value below your significance level, usually 0.05, says at least one average differs. In the example F = 19.3214 and p = 0.000177.

      Which groups are different?

      ANOVA alone does not say. A post hoc test compares each pair while keeping the overall false alarm rate in check. In the example Tukey gives p = 0.005779 for A and B, 0.09897 for A and C and 0.0001361 for B and C, so B stands apart from the other two.

      What do the letters on the picture mean?

      Groups that share a letter are not shown to differ. Groups with no letter in common are significantly different. In the example Method B has the letter a, and Methods A and C share the letter b.

      What are the assumptions of one-way ANOVA?

      Each value comes from a separate subject, the values in every group are roughly normal, and the groups have similar spread. The page checks the last two with Shapiro-Wilk and Levene. Independence has to come from how you collected the data.

      What if the spreads are unequal?

      Use Welch’s ANOVA, which does not assume equal variances, followed by Games-Howell comparisons. The page recommends it when Levene’s test finds a difference in spread.

      What if my data are not normal?

      With small groups that clearly depart from normality, the Kruskal-Wallis test works on ranks. In larger groups, at least 15 values each for up to 9 groups, ANOVA copes well with moderate departures.

      Can I run ANOVA with only means and standard deviations?

      Yes. Choose Summary and type each group’s size, average and standard deviation or standard error. The classic and Welch tests and the pair comparisons work; the normality, spread and rank tests need the raw values.

      What is eta squared?

      The share of all the variation that lies between the groups: between-groups sum of squares divided by the total. In the example it is 0.763. Cohen’s f turns it into √(η² ÷ (1 − η²)), here 1.7945.

      How many values do I need per group?

      It depends on the effect you want to detect. With three groups and α = 0.05, 80% power needs about 323 values per group for a small effect (f = 0.1), 53 for a medium one (0.25) and 22 for a large one (0.4).

      I only have F and the degrees of freedom. Can I get the p-value?

      Yes. Choose F value and type the two degrees of freedom and F. For F = 4.5 with 2 and 12 degrees of freedom p = 0.03482. Leave F empty to get the critical value, 3.8853 at 0.05.

      Does this calculator do two-way ANOVA?

      No. This page handles one factor: groups that differ in one way. Designs with two factors, or the same subjects measured repeatedly, need a different analysis.
