## Competitors opened LIVE 2026-11-22 (4 usable)
1. **Omnicalculator** (statistics/t-test): test type one-sample / two-sample / paired; alternative (two-tailed / < / >); approach p-value or critical values; alpha; the user types the t-score and degrees of freedom (NO sample data or means); output p-value (or critical values). Plus long text (formulas, t vs z, FAQ). It is only a t -> p converter.
2. **GraphPad QuickCalcs** (ttest1): data entry as up to 50 rows, up to 2000 rows pasted, mean+SEM+N, mean+SD+N; tests unpaired (Student), Welch, paired; always two-tailed; separate one-sample page; labels; results table (P value, t, df, means, SE, CI of the difference); help text on which test.
3. **Social Science Statistics** (studentttest): two pasted lists; method Welch or pooled; alpha 0.01 / 0.05 / 0.10; alternative two-sided / > / <; shows differences from mean, squared differences, SS, per-group N / mean / variance; standard error, t, df, mean difference, 95% CI, three p-values (>, <, two-tailed), significant yes/no sentence, citation styles (APA parenthetical, APA narrative, Chicago, plain English) with Copy. No chart.
4. **Stats Kingdom** (t-test-calculator): four tests (pooled, Welch, paired, one-sample); tails; alpha; raw grid (Excel paste, CSV upload, delimiter options) or summary (mean, SD, n); expected difference d; options for rounding, outliers, effect size; output: APA sentence, p, t, df, difference, standard error, Cohen's d, pooled SD, a priori + post hoc power, per group mean / SD / n / normality p / skewness / outliers (Tukey), step-by-step formulas, t curve with shaded rejection regions and t marker, acceptance region, confidence interval, validation notes (normality Shapiro-Wilk, outliers, power advice), R code, Copy, Print, last run.
Not opened (404 or not found): calculator.net (no t-test page), Statology calculator page. Not verified: what Google ranks top today.

## Differentiators (none of the four has them)
**Visual (one):** an estimation plot on the user's OWN units: every data point of both groups as dots on one axis, group means as bars/markers with their CI whiskers, and below it the difference with its CI on a second axis with a zero line; if the CI crosses zero the plot says so. (Stats Kingdom draws only the abstract t curve; others draw nothing.) For paired data: lines joining each pair.
**Functional (main):** (1) pooled AND Welch AND (when data are paired) paired shown side by side from the same data, with a plain-English line saying which one fits (equal-variance ratio) and whether the choice changes the conclusion, so the user does not have to guess the test; (2) "What would it take": the smallest difference that would be significant at this spread and n, and how many people per group would be needed for p < alpha / 80% power at the observed effect (no competitor shows this; Stats Kingdom shows power only as a number).
**Go advanced:** expected difference d, own confidence level, critical-value approach, t and df typed directly (Omni parity), mean + SEM entry, Cohen's d with interpretation bands (only if a source is read), group labels, decimals.
Result headline = the decision sentence with p; sticky mobile bar = live p and difference.
