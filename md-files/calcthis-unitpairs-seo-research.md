# Unit-pair converter pages: SEO research + conclusions (2026-11-12, session #10)

Scope: the 17 pair pages generated by `md-files/gen-unit-pages.js` (PAIRS array). GSC (read 2026-11-11): unit pairs are among the 25 "crawled, currently not indexed" pages.

## Findings
1. Overlap between pairs is NOT the problem: `md-files/dup-check.js` 8-word runs = 5-12% between pair pages (cm-to-inches vs mm-to-inches 8.6/10.1, kg-to-lbs vs grams-to-ounces 8.4/7.7, mb-to-gb vs kb-to-mb 10.3/12.0, celsius pair 9.8, cups-to-grams vs cups-to-tablespoons 4.8/7.6).
2. The problem is DEPTH. Visible content of our pair page = formula + 1-2 steps paragraphs + two small value tables (6-9 rows) + 5 FAQs (about 350-600 words). Competitors opened live 2026-11-12:
   - Inch Calculator (cm to inches, kg to lbs, cups to grams): H2 sections "How to convert", "How many X in a Y", fractional inches step by step, higher-precision formula, mixed measurement (lb + oz), "What is a centimeter / inch" with definitions (meter via speed of light, 2019 kilogram via Planck constant), full 1-100 table, references, reviewer byline, common-weights links; cups to grams has ~110-ingredient dropdown + water table by fraction + density source (FAO).
   - Metric-conversions.org (cm to inches, Celsius to Fahrenheit): accuracy selector (1-8 significant figures), worked calculation shown line by line, mental shortcut with its error (x4 / 10 = 1.6% high; double + 30), what the units are, which countries use which, full 0-79 table.
   - UnitConverters.net (mb to gb; cm-to-inch URL was a 404): definition + history + current use of both units, decimal vs binary note.
3. What we already do better (keep, do not touch): every unit at once, swap, tape-measure fractions, lb + oz split, thermometer, dual ruler, cups to grams for 50 ingredients with 3 cup standards, GiB vs GB, exact factors, copy button.
4. What competitors have that we lack on the PAGE (a crawler sees text, not the widget): definition of both units with source, a mental-math shortcut with its error size, a longer reference table (we show 6-9 rows), a worked example shown step by step, where each unit is used (countries / trades), common mistakes, a precision note, references.

## Conclusion (SEO first)
Do NOT merge pairs and do NOT noindex them: each is a separate head keyword with its own demand (Ahrefs, his 2026-10-31 screenshots). Fix = give every one of the 17 pages 350-500 words of UNIQUE, sourced, pair-specific text (generated from the engine where numeric so text and tool agree) and keep the converter widget untouched:
- "What is a {unit A} and a {unit B}" (definition, exact factor, who defines it) from sources I read.
- "Quick mental math" shortcut + its measured error (computed by the engine across the table, not typed from memory).
- "Common mistakes" specific to the pair (cups: volume vs weight, US vs metric cup 236.588 vs 250 mL, tablespoon 14.787 mL US; other countries' tablespoon only if a source is read; MB: decimal vs binary, MB vs Mb; Celsius: add 32 before or after; knots: nautical mile 1,852 m exact).
- Longer reference table (fits the pair: 20-30 rows or key round numbers: shoe/ruler/phone/recipe/oven/file-size values), generated by the engine.
- "Where it is used" per pair (only facts from read sources).
- Sources block with the exact documents, dated.
Sources READ 2026-11-12: NIST SP 811 Appendix B.8 (inch 2.54 cm exact, lb 0.45359237 kg, oz 28.349 52 g, mile 1.609 344 km, yard 0.9144 m, foot 0.3048 m, knot 0.514 444 m/s, US cup 236.5882 mL, tablespoon 14.78676 mL, teaspoon 4.928922 mL, deg F to deg C = (F - 32)/1.8, K = C + 273.15). STILL TO READ at build time, else dropped: BIPM SI brochure (2019 kilogram / kelvin definitions), IEC 80000-13 or NIST on binary prefixes, NIST Handbook 44 for gallon/quart, FAO density source for ingredients (cups to grams values are already typical values and flagged).
Differentiators vs competitors for these pages: unchanged widget (visual + functional) PLUS equal or greater written depth, so no gap remains on text.
