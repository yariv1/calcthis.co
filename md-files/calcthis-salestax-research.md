# Sales Tax Calculator — research, decisions, how to add a state (2026-10-28, built local v206, NOT deployed)

**SEO structure (user + SEO-first):** hub `/sales-tax-calculator/` (head >10K Hard) + one page per state `/sales-tax-calculator/<slug>/` (state pages are >1K: NJ, MO, OH, MN Easy; TX, CA, NYC Hard) — same pattern as Paycheck. Year variants ("texas sales tax calculator 2026") are <100 → NO pages, year goes in title/content. Other intents with their own demand (later pages): `car sales tax calculator` (>1K Easy), `reverse sales tax calculator` (>1K Hard — covered as a mode on every page).

**Competitors opened live (2026-10-28):** calculator.net (3 fields, solve any one, state rate table, no visuals), salestaxcalculator.net NJ (ZIP -> rate, price -> tax/total, ads), Omni NJ (price + ZIP), best-calculators NJ (price, delivery, taxable share %, rate mode std/UEZ/exempt/custom, presets). **Blocked by Cloudflare: salestaxhandbook.com, salestaxstates.com** (not verified; ask the user for a screenshot if parity is in doubt).

**Differentiators built:** every extra shown by default (special zones, other taxes list, shipping rule), forward + reverse + find-the-rate in one page, multi-item list with taxable/exempt per item, shipping split by price, use-tax-owed for online/out-of-state buys (Go advanced), "same purchase next door" strip, where-your-money-goes bar, sourced + dated rates. **Gap vs competitors: no ZIP auto-fill** (NJ is flat; ZIP lookups need a licensed rate DB — plan: city/county dropdown from official tables where sourceable, e.g. TX/OH).

**Rules the user set (permanent):** NEVER guess; wherever extra charges exist show them to the user without him having to know they exist; unverified state = "state rate only" + sourced highest-local range (Tax Foundation) + optional own-rate field; shipping on unverified states is a visible checkbox ("My state charges sales tax on shipping"), default OFF; a state page goes live only when its rate, exempt categories, zones and shipping rule come from the state's own guidance.

**Code:** `CalcThis.saleTaxEngine` (pure, `SALESTAX-ENGINE:START/END` in assets/app.js; STATES = all 50 + DC from Tax Foundation July 1 2026 table; NJ record has `live:true`, cats, zones, shipNote, others, src, eff) + `CalcThis.initSalesTaxCalc` (ids `st*`); CSS `.p-stax` (body `p-loan p-stax`); pages generated by `node md-files/gen-salestax-pages.js` (hub + every `live` state; also registers sitemap, llms.txt, partials header/footer, build.js PAGES, homepage card/hasPart); then `node build.js`. State pages use `<body data-state="NJ">`; the State dropdown navigates (carries price/shipping via sessionStorage `stForm`; test hook `window.__stNoNav=true`).

**Add a state:** (1) research the state's official guidance (rate, exempt/taxable categories, local taxes + exact local tables if any, special zones, shipping rule, source URL + date); (2) add its `Object.assign(S.XX, {live:true, slug, eff, src, cats[{id,label,long,taxable,note}], zones[{id,std|rate,cats,ignore,label}], shipNote, others[{t,d}], nearby})` in the engine; (3) add FACTS.XX intro + state-specific FAQs in the generator (faqsFor is NJ-worded — generalise per state); (4) run generator + build; (5) QA (matrix of cat x zone x amounts vs independent formula, garbage grid, fuzz, 375px screenshots).

**NJ facts used (official, NJ Division of Taxation S&U-4 rev. 07/22 + S&U-5 rev. 5/25):** 6.625% statewide (Tax Foundation July 2026 confirms); exempt: most grocery food, clothing/footwear (not fur, accessories, sports/recreational/protective equipment), Rx + OTC drugs, household paper products; taxable: prepared food, candy, soft drinks, alcohol, tobacco; UEZ (certified seller, in person) and Salem County (in-person goods, not mail-order/prepared food/alcohol/vehicles/services) = 3.3125%; Atlantic City luxury tax 9% (3% bar drinks), combined cap 12.625%; Wildwood/Wildwood Crest/North Wildwood +2% tourism on restaurant food, lodging, admissions; hotel occupancy fee 5% (1% Newark/JC/AC, 3.15% Wildwoods) + up to 3% municipal; delivery follows item taxability (mixed shipment split by price or weight; unsplit = all taxable); use tax 6.625% on price + delivery, credit for lower tax paid elsewhere (official examples $202.06 and $45.00 verified against the engine). **Not computed (shown as info only):** Atlantic City luxury tax, hotel fees.

**Homepage tab (2026-10-28, deployed v212):** a "Sales Tax Calculators" tab (`#grp-salestax`) with an All-states cube + one flag cube per live state, generated between <!--STAXCUBES--> markers by gen-salestax-pages.js. **A new live state needs its flag file** `assets/flags/xx.webp` (60x40; NJ done) — see HANDOFF Paycheck tab note.

**Dropdown rule (user, 2026-10-28):** the State dropdown lists ONLY live states (plus "Any state — enter my own rate"); never list states that have no page yet. Add a state to the dropdown by making it `live:true`.

## Missouri research (2026-10-28, official sources — page NOT built yet, waiting on the place-picker decision)
- **State rate 4.225%** (3.0 general revenue + 1.0 education + 0.125 conservation + 0.10 parks/soils). Source: dor.mo.gov/taxation/business/tax-types/sales-use/
- **Local taxes** (cities, counties, districts) are ADDED on top; seller collects the combined rate at the seller's location. Every location has local tax: official table (Oct-Dec 2026, run 8/25/2026, https://dor.mo.gov/pdf/rates/2026/october2026.pdf, 2,597 rows) combined general rate ranges **5.225% – 11.488%** for city/county base rows (1,644), up to **13.238%** inside special districts (CID/TDD); food column 2.225% – 8.1% (9.85% in districts). Rates change each quarter (Jan/Apr/Jul/Oct).
- **Food (groceries):** state rate reduced to **1.225%** (RSMo 144.014); ALL local taxes still apply to food in full (so food rate = official "Food Sales Tax" column). Restaurants/prepared food where prepared food is >80% of gross receipts: full rate on everything. Source: dor.mo.gov/taxation/business/tax-types/sales-use/reduction-on-food.html
- **Prescription drugs exempt** (also insulin, hearing aids, prosthetics); OTC medicine taxable (exempt only if bought by a person with a disability, or prescribed). Source: dor.mo.gov/faq/taxation/business/sales-use-tax-exemptions.html. No clothing exemption is documented on the DOR pages read — do NOT claim clothing is taxable/exempt without a source. Candy / soft drinks / alcohol: DOR pages read do not address them — do not claim.
- **Delivery:** separately stated, usual-and-customary delivery charges are NOT taxable (RSMo 144.010 / 144.605(8); DOR letter ruling LR 8387, 2026-03-24); a combined "shipping and handling" fee is taxable in full (LR 8359).
- **Use tax** 4.225% + local use tax; return required above $2,000 purchases a year. Food truck sales = full rate of the location.
- Sample official base rates (general / food): St. Louis city 9.679 / 6.391; Kansas City Jackson Co. 8.975 / 5.975, Clay Co. 8.725 / 5.725, Platte 8.725 / 5.725, Cass 9.1 / 6.1; Springfield 8.1 / 5.1; Columbia 7.975 / 4.975; Independence (Jackson) 8.6 / 5.6; Lee's Summit (Jackson) 8.475 / 5.475; St. Joseph 9.7 / 6.7; Joplin (Jasper) 8.725 / 5.725; St. Charles Co. cities 7.45–8.45. Parsed file: scratchpad mo/recs.json (parse.js).
- Hub table currently says Missouri highest local 6.25% (Tax Foundation) — the official table shows up to 7.263% (city/county) so the page must use the official range.

## Missouri DEPLOYED (2026-10-28, v224) — the place-lookup pattern (use for every state with local rates)
- User decision: **searchable typeahead of every official place** (user: "option 1 - make it a typeahead"). Data = the DOR Oct-Dec 2026 table (xlsx, run 8/25/2026) -> `assets/data/mo-rates.json` (2,597 rows `[label, sales, use, food, foodUse]`, 231 KB, fetched ONLY on the Missouri page). Rebuilt from the xlsx by scratchpad `mo/mk.py` (openpyxl; labels title-cased, Amb->Ambulance, FIR->Fire). **Quarterly refresh needed (Jan/Apr/Jul/Oct): re-download dor.mo.gov/pdf/rates/<year>/<month><year>.xlsx, rerun mk.py, update lo/hi/baseHi/foodLo/foodHi + `eff` in the engine MO record.**
- Engine: state record `places:{url,n,lo,hi,baseHi,foodLo,foodHi}`; cats may carry `rate:'food'` (uses the place's food column); `rateFor` takes `place` and returns `needsPlace` when none picked; use tax uses the place's use / foodUse columns; `shipOpt` states tax shipping only when the user ticks "billed as one charge" (default untaxed = separately stated delivery).
- UI: `#stPlaceFld` (typeahead, shown right under State) in the shared template; no place picked -> big result stays blank and the sub-line shows the official range for the entered amount ("$105.23 to $113.24"); sticky bar says "Pick your place". Failed table load -> clear message + own-rate escape hatch.
- Page: generator `writePlaceState()` + `moFaqs()` (all numbers from the engine); city table of 17 places; hub table shows "varies by place". State dropdown lists live states only.
- **Facts NOT to claim (no official source found):** candy / soft drinks / alcohol treatment; food = state 1.225% + full local (true for 2,038 of 2,597 rows only — the DOR food column is authoritative, some places differ by 0.1-1%).
- QA done: engine matrix 72,716 combos over all 2,597 places x 4 cats x 7 amounts (tax, total, reverse round trip, shipping both ways, use tax, own override) = 0 failures; every one of the 2,597 places picked through the real typeahead and checked against independent math; 60 hostile random runs + 400 random-control steps with invariants (parts=total, headline=table=mbar, no NaN, no horizontal scroll, no dup ids, no console errors); NJ regression; hub -> Missouri navigation carries price + shipping; data-load failure path; 375px + desktop screenshots. ## Ohio DEPLOYED (2026-10-28, v233)
- Same place-lookup engine as Missouri; data `assets/data/oh-rates.json` = Ohio DOR "Sales and Use Tax Rates by County, Oct 1 - Dec 31, 2026" (88 counties + 5 transit-area rows: COTA parts of Delaware/Fairfield/Licking/Union, TARTA part of Wood) built by scratchpad `oh/build.js` (rates copied from https://tax.ohio.gov/business/sales-and-use-tax/rate-tables/by-county-q4-2026 — only reachable through the Browser pane, bots get 403). Range 6.5% (Butler, Lorain, Stark, Wayne) - 8% (Cuyahoga, Franklin), 8.25% in the Reynoldsburg part of Licking. State 5.75%; legal cap 8.75%; changes only on Jan/Apr/Jul/Oct 1 (Warren 6.75 -> 7.25 on 2026-10-01). **Refresh quarterly.**
- Official rules used: taxability page (clothing, OTC drugs, vitamins/supplements, soft drinks, alcohol, tobacco, prepared/eat-in food taxable; takeout/off-premises food exempt; Rx, doctor-prescribed equipment, Rx glasses/contacts, children's diapers/cribs/strollers/car seats, feminine hygiene exempt); ST 2004-01 food definition (R.C. 5739.02(B)(2)); OAC 5703-9-52 delivery (seller delivery charge = part of price; split by price/weight in mixed shipments; unsplit mixed = whole charge taxed; carrier paid directly not taxed); 2026 holiday Aug 7-9 (clothing <= $75, school supplies and instructional materials <= $20) — dates/limits set yearly, not applied by the calculator.
- Not claimed (no official source read): candy treatment; sourcing detail beyond "usually where you receive the item". City names in the county labels are convenience aliases only (cities that span counties left out, except Dublin/Westerville/Reynoldsburg shown under Franklin where most of each lies).
- Engine/UI additions: `places.noFood`, `places.hint/ph/hubNote`; typeahead ranks rows without " — " first. QA: engine matrix 3,255 combos over all 93 rows (0 failures), all 93 picked through the real UI, 300 random control steps, MO regression (650 places re-picked), 375px screenshots, hub dropdown + homepage tab. Not verified: real phone, real Chrome (Copy), print.
- **Typeahead rules (user, 2026-10-28):** the place field is `type="search"` (native X, same as the menu search); focusing an EMPTY field opens the whole list (scrollable, drawn in chunks of 120, so Missouri's 2,597 rows open instantly); focusing a field that already holds a pick selects its text and reopens the full list at the current pick; the input shows a SHORT name when the label is long (`places.short`, Ohio county + its cities / transit rows) and the full label + rate go in the note under the field; typing narrows (60 max + "keep typing"), rows without " — " rank first.
