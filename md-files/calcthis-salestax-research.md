# Sales Tax Calculator — research, decisions, how to add a state (2026-10-28, built local v206, NOT deployed)

**SEO structure (user + SEO-first):** hub `/sales-tax-calculator/` (head >10K Hard) + one page per state `/sales-tax-calculator/<slug>/` (state pages are >1K: NJ, MO, OH, MN Easy; TX, CA, NYC Hard) — same pattern as Paycheck. Year variants ("texas sales tax calculator 2026") are <100 → NO pages, year goes in title/content. Other intents with their own demand (later pages): `car sales tax calculator` (>1K Easy), `reverse sales tax calculator` (>1K Hard — covered as a mode on every page).

**Competitors opened live (2026-10-28):** calculator.net (3 fields, solve any one, state rate table, no visuals), salestaxcalculator.net NJ (ZIP -> rate, price -> tax/total, ads), Omni NJ (price + ZIP), best-calculators NJ (price, delivery, taxable share %, rate mode std/UEZ/exempt/custom, presets). **Blocked by Cloudflare: salestaxhandbook.com, salestaxstates.com** (not verified; ask the user for a screenshot if parity is in doubt).

**Differentiators built:** every extra shown by default (special zones, other taxes list, shipping rule), forward + reverse + find-the-rate in one page, multi-item list with taxable/exempt per item, shipping split by price, use-tax-owed for online/out-of-state buys (Go advanced), "same purchase next door" strip, where-your-money-goes bar, sourced + dated rates. **Gap vs competitors: no ZIP auto-fill** (NJ is flat; ZIP lookups need a licensed rate DB — plan: city/county dropdown from official tables where sourceable, e.g. TX/OH).

**Rules the user set (permanent):** NEVER guess; wherever extra charges exist show them to the user without him having to know they exist; unverified state = "state rate only" + sourced highest-local range (Tax Foundation) + optional own-rate field; shipping on unverified states is a visible checkbox ("My state charges sales tax on shipping"), default OFF; a state page goes live only when its rate, exempt categories, zones and shipping rule come from the state's own guidance.

**Code:** `CalcThis.saleTaxEngine` (pure, `SALESTAX-ENGINE:START/END` in assets/app.js; STATES = all 50 + DC from Tax Foundation July 1 2026 table; NJ record has `live:true`, cats, zones, shipNote, others, src, eff) + `CalcThis.initSalesTaxCalc` (ids `st*`); CSS `.p-stax` (body `p-loan p-stax`); pages generated by `node md-files/gen-salestax-pages.js` (hub + every `live` state; also registers sitemap, llms.txt, partials header/footer, build.js PAGES, homepage card/hasPart); then `node build.js`. State pages use `<body data-state="NJ">`; the State dropdown navigates (carries price/shipping via sessionStorage `stForm`; test hook `window.__stNoNav=true`).

**Add a state:** (1) research the state's official guidance (rate, exempt/taxable categories, local taxes + exact local tables if any, special zones, shipping rule, source URL + date); (2) add its `Object.assign(S.XX, {live:true, slug, eff, src, cats[{id,label,long,taxable,note}], zones[{id,std|rate,cats,ignore,label}], shipNote, others[{t,d}], nearby})` in the engine; (3) add FACTS.XX intro + state-specific FAQs in the generator (faqsFor is NJ-worded — generalise per state); (4) run generator + build; (5) QA (matrix of cat x zone x amounts vs independent formula, garbage grid, fuzz, 375px screenshots).

**NJ facts used (official, NJ Division of Taxation S&U-4 rev. 07/22 + S&U-5 rev. 5/25):** 6.625% statewide (Tax Foundation July 2026 confirms); exempt: most grocery food, clothing/footwear (not fur, accessories, sports/recreational/protective equipment), Rx + OTC drugs, household paper products; taxable: prepared food, candy, soft drinks, alcohol, tobacco; UEZ (certified seller, in person) and Salem County (in-person goods, not mail-order/prepared food/alcohol/vehicles/services) = 3.3125%; Atlantic City luxury tax 9% (3% bar drinks), combined cap 12.625%; Wildwood/Wildwood Crest/North Wildwood +2% tourism on restaurant food, lodging, admissions; hotel occupancy fee 5% (1% Newark/JC/AC, 3.15% Wildwoods) + up to 3% municipal; delivery follows item taxability (mixed shipment split by price or weight; unsplit = all taxable); use tax 6.625% on price + delivery, credit for lower tax paid elsewhere (official examples $202.06 and $45.00 verified against the engine). **Not computed (shown as info only):** Atlantic City luxury tax, hotel fees.

**Homepage tab (2026-10-28, deployed v212):** a "Sales Tax Calculators" tab (`#grp-salestax`) with an All-states cube + one flag cube per live state, generated between <!--STAXCUBES--> markers by gen-salestax-pages.js. **A new live state needs its flag file** `assets/flags/xx.webp` (60x40; NJ done) — see HANDOFF Paycheck tab note.
