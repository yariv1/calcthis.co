# AdSense plan — calcthis.co (written 2026-11-18)

**Status:** "Low value content" (updated 2026-11-16). Google's message tests: substantial unique value (we have it), a consistent presence on the web, and user interest. Tests 2 and 3 = footprint + traffic, not page content. Search Console 2026-11-13: 3 clicks / 913 impressions in 90 days, 139 of 210 pages indexed.

**Goal:** indexed pages, outside mentions and real visitors, then request review. Nothing else (no new templated pages, no pruning of paycheck pages).

## 1. Claude, this week (no cost, no risk)
1. About page: add the method (sources, how each result is checked against independent maths and competitors, corrections email). Add a "What's new" page (release log) linked in the footer.
2. Visible upkeep: "Updated <date>" on every calculator page from the build; sitemap `lastmod` from the same date.
3. Indexing: GSC "Start queue" each day (about 11 per window) + Bing submit for every new URL. Order: knots-to-mph, tablespoons-to-teaspoons, tablespoons-to-ml, tip hub + 8, paycheck states from kentucky.

## 2. You + Claude, every week (the footprint)
1. Reddit: 3 helpful comments a week on relevant threads (you send the thread, I draft, one natural link, you post).
2. Listings: Product Hunt, AlternativeTo, Indie Hackers, "free online tools" directories, Show HN for the 3 strongest tools. One a week, I write the text.
3. Profiles: one X, LinkedIn and Facebook page, Pinterest boards of result visuals. Same logo and name, link to the site.
4. One citable data page a month (for example yearly tax numbers or paycheck tables) so bloggers have something to link to.

## 3. Traffic (after Nov 26)
1. Read Search Console: pages with impressions but few clicks get a better title and description.
2. Push the 5 pages with the best chance to rank (Easy, over 1,000 searches) with internal links and one outside link each.

## 4. Checkpoints (our own targets, Google publishes none)
| Date | Check | Target |
|---|---|---|
| Nov 26 | Indexed pages | above 160 |
| Dec 8 | Indexed pages / weekly clicks | above 200 / rising each week |
| Dec 15 | Request AdSense review only if both targets are met and outside links exist | else wait 2 more weeks |

Do not request a review before the Dec 15 check: each rejection restarts the wait with no new evidence.
