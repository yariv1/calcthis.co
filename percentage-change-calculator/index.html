    How to use the percentage change calculator

    Pick what you want to find. Percent change takes a starting and an ending value. Final value takes a starting value and a percentage (use a minus sign, or the Decrease button, for a drop). Starting value works backwards from an ending value and a percentage.

    Below the answer you get a before-and-after bar, the working, the change in absolute terms, the multiplier, and the percentage you would need to get back to the start. Values can include $ and commas, or be times like 1:30:00.

    The percentage change formula

    % change = (end − start) ÷ |start| × 100 POSITIVE = INCREASE · NEGATIVE = DECREASE

    From 80 to 96: (96 − 80) ÷ 80 × 100 = +20%. From 96 back to 80: (80 − 96) ÷ 96 × 100 = −16.67%. The two are different because each is measured from a different starting point.

    Why going back needs a different percentage

    ChangePercentTo get back
    100 → 125+25%−20%
    80 → 96+20%−16.67%
    100 → 50−50%+100%
    100 → 200+100%−50%

    That is why +25% then −25% leaves you at 93.75, not 100.

    Percent increase and percent decrease

    They are the same formula. A positive result is a percent increase, a negative one is a percent decrease — the calculator labels it either way, so there is no need for two tools. A decrease can never be more than 100% (that takes the value to zero), but an increase can be any size.

    Negative and zero starting values

    The formula divides by the absolute value of the start, so the answer keeps its meaning: −25 to 25 is +200% (an increase of 50 on a base of 25) and −25 to −50 is −100%. A start of 0 has no percentage — the calculator says so and shows the absolute change instead.

    Percent change vs percentage points

    When both values are themselves percentages, the plain difference is in percentage points. A rate that goes from 2% to 3% rises +1 point but +50% in relative terms. Switch on Go advanced and choose "Percentages" to see both.

    A list of values over time

    Paste values in order under Go advanced — monthly sales, yearly prices, anything — to see the change from each value to the next, the total change from first to last, the average of the period changes and the compound rate per period. For 100, 110, 99, 120 that is +10%, −10%, +21.21%, a total of +20% and +6.27% a period compounded.

    For percent of a number, or what percent one number is of another, use the percentage calculator; for the average of a list, the average calculator; to see what a pay raise does to hourly, monthly and yearly pay, the salary calculator.

    Common questions

    How do you calculate percentage change?

    Subtract the starting value from the ending value, divide by the starting value, and multiply by 100: (end − start) ÷ start × 100. Going from 80 to 96 gives (96 − 80) ÷ 80 × 100 = +20%. A positive answer is an increase, a negative one a decrease.

    Why does a 25% rise followed by a 25% fall not get me back to where I started?

    Because the second percentage is measured from a bigger number. 100 up 25% is 125; 125 down 25% is 93.75, a net change of −6.25%. To get back from 125 to 100 you need a −20% change. The calculator always shows the percentage you need to get back.

    How do I find the percentage change when the starting value is negative?

    Divide by the absolute value of the starting value, which keeps the sign meaningful: going from −25 to 25 is (25 − (−25)) ÷ |−25| × 100 = +200%, an increase, and from −25 to −50 is −100%, a decrease. Percent change is easiest to interpret when both values are positive, so the calculator adds a note when the start is negative.

    What if the starting value is zero?

    The percent change is undefined: there is no starting size to compare with, and dividing by zero has no answer. From 0 to 0 there is no change (0%). The calculator says so in plain words and still shows the absolute change.

    What is the difference between percent change and percentage points?

    If a rate rises from 2% to 3%, it went up by +1 percentage point — but the percent change is +50%, because 3 is half as big again as 2. Open Go advanced and set the values to percentages to see both side by side.

    How do I find the original value after a percentage increase?

    Divide the final value by 1 plus the percentage as a decimal. If a price is 120 after a 20% increase, the original was 120 ÷ 1.2 = 100. Choose "Starting value" at the top of the calculator and enter the end value and the percentage.

    How do I calculate the new value after a percentage increase or decrease?

    Multiply the starting value by 1 plus the percentage (as a decimal). 80 increased by 25% is 80 × 1.25 = 100; a decrease uses a minus, so 80 down 25% is 80 × 0.75 = 60. Choose "Final value" at the top.

    Can I find the percentage change across a whole list of values?

    Yes — open Go advanced and paste the values in order. For 100, 110, 99, 120 you get +10%, −10% and +21.21% for each step, a total of +20%, and a compound rate of +6.27% per period.

    Does it work with times?

    Yes. Enter times such as 1:30:00 and 1:12:00 (h:mm:ss) or 1:30 and 1:12 (m:ss) in both boxes: the change from 1:30:00 to 1:12:00 is −20%. Use the same format in both boxes.
